## Project Structure & Architecture

This is a personal data analysis, automation, and portfolio workspace with three main areas:

### 1. EDA / Data Analysis (`00_RESULTS/`)
Results are organized in numbered subdirectories (e.g., `00_eda_monthly_sales`). Each subdirectory contains:
- A Python analysis script
- An output `.png` chart (generated via Plotly → Kaleido)
- A Markdown report (auto-generated by the script)

The analysis pipeline reads raw SQL dump files, parses `INSERT INTO` statements with a custom regex parser (no DB connection needed), aggregates with pandas, visualizes with Plotly, and writes a Markdown report.

**Data source**: Olist E-Commerce SQL dump at `C:\Users\wnsdu\Desktop\프로그래밍\DATAAI_FUNCODING_V1_3\00_DATAAI_FUNCODING\01_DATAS\olist_ecommerce.sql`

### 2. Personal Portfolio Website (`quotes.html`)
A single-file personal introduction webpage for Junyoung Bang, built with HTML/CSS/JS.
- Dark theme with gold accents (`#c9a84c`), responsive layout
- Sections: Hero (name, summary, contacts), Skills, Industry Experience, Research Experience, Education
- Content sourced from `Junyoung_Bang_Resume_수정2.docx`
- Features: fixed nav with scroll-spy, Intersection Observer fade-in animations, CSS custom properties
- Open directly in browser — no build step needed

### 3. LinkedIn Automation (`linkedin_scraper.py` + `회사 사람 정리.xlsx`)
A pipeline that:
1. Reads LinkedIn profile URLs from an Excel file (`회사 사람 정리.xlsx`, sheet `people`, column F)
2. Uses Playwright (headless=False) to scrape profile text — requires manual login in the opened browser
3. Sends profile text to Claude API (`claude-opus-4-6` with `thinking: adaptive`) for structured extraction
4. Writes results (company, school, title, career insight) back into the Excel file row by row

**Claude API key**: Must be set via `ANTHROPIC_API_KEY` environment variable.

**Excel column mapping** (configurable at top of `linkedin_scraper.py`):
- F → LinkedIn URL (input)
- C → Company, D → School, E → Title, G → Insight (output)

`create_template.py` generates a blank `linkedin_template.xlsx` with the correct headers and column widths.
